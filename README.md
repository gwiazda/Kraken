# Kraken

Internal management system for **Krak Coffee Roastery**: green coffee inventory, roasting log, invoice requests,
contractor price lists and cost calculation.

A static site (TypeScript + Vite) on GitHub Pages, with Google Sheets as the database and Google sign-in.
Only the two owners have access to the data.

## Run locally
```sh
npm install     # once
npm run dev     # then open http://localhost:5173/
```

See `CLAUDE.md` for the architecture and decisions, `docs/REQUIREMENTS.md` for the requirements and `STATUS.md` for current work.
